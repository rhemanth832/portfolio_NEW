# Rasamsetty Hemanth — Portfolio

A responsive, accessible portfolio with a navy-and-teal palette, locally hosted Inter typography, a sticky introduction, and eight navigable sections. Built with HTML, CSS, and vanilla JavaScript. No installation or build step is required.

## Content

- About / professional summary
- Internship at Tap Academy
- RAGbot and Academia Share projects
- Languages, web technologies, tools, foundations, and soft skills
- All three education entries
- Patent record, IJSDR publication, hackathons, and club coordination
- Salesforce, IBM, and Blackbugs credentials
- Email, phone, GitHub, and LinkedIn contact links

The Download Resume button opens the supplied Google Drive file.

## Editing

Edit `dist/index.html` for content and links, `dist/styles.css` for presentation, and `dist/script.js` for the scroll indicator, active navigation, and copy-email interaction.

To preview locally, open a terminal in `dist`, run cd `dist`, `py -m http.server 8000` on Windows or `python3 -m http.server 8000` on macOS/Linux, and visit `http://localhost:8000`.
